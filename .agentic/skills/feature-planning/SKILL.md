# Feature Planning

Read project/framework instructions and architecture contract; inspect relevant code/tests; create `tasks/active/<feature>.md` from the template; assign stable task IDs; include acceptance criteria, dependencies, expected verification and architecture impact. Identify protected decisions. Do not modify application behavior during planning-only work.
